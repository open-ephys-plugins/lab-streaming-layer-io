# Resources

## scripts

### SendNeuralData.py

This script generates and sends a neural data stream to the LSL outlet.

### SendSineData.py

This script generates and sends a sine data stream to the LSL outlet.

### SendMarkerData.py

This script generates and sends a marker data stream to the LSL outlet.

## marker map

### ex_marker_map.json

This file contains an example mapping of marker names to event channel numbers.

It is used to map markers to event channels in the MarkerData stream.

The mapping is as follows:

```
{
    "Marker_1": 1,
    "Marker_2": 2
}
```
